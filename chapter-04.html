บทที่ 4 สแตกและคิว (Stack and Queue)

วัตถุประสงค์การเรียนรู้

เมื่อเรียนจบบทนี้ นักศึกษาจะสามารถ

  1. อธิบายหลักการ LIFO (Last-In, First-Out) ของสแตก
  2. อธิบายหลักการ FIFO (First-In, First-Out) ของคิว
  3. อธิบายการดำเนินการพื้นฐานของสแตกและคิว (push, pop, enqueue, dequeue)
  4. ประยุกต์ใช้สแตกและคิวในการแก้ปัญหาเบื้องต้น
  5. แยกแยะสแตกธรรมดา คิวธรรมดา คิวแบบวงกลม และเด็กซ์ (Deque)

4.1 สแตก (Stack) และหลักการ LIFO

สแตกคือโครงสร้างข้อมูลที่การเพิ่มและลบเกิดขึ้นที่ด้านเดียวเรียกว่า ยอดสแตก (top)

หลักการ LIFO (Last-In, First-Out) คือ ตัวที่เข้าไปทีหลังจะออกมาก่อน เปรียบเสมือนกองจาน หรือกล่องทับกัน

graph TD
    subgraph Stack[สแตก - LIFO]
        direction TB
        T4([40]) -->|pop| T3([30])
        T3 -->|pop| T2([20])
        T2 -->|pop| T1([10])
        T1 -->|bottom| Base[(พื้น)]
    end
    
    Push[push 10] --> T1
    Push -->|push 20| T2
    Push -->|push 30| T3
    Push -->|push 40| T4

การดำเนินการกับสแตก

การดำเนินการคำอธิบายความซับซ้อน
push(x)ใส่ x ที่ยอดสแตกO(1)
pop()เอาตัวที่ยอดออกและคืนค่าO(1)
peek()ดูค่าที่ยอดโดยไม่เอาออกO(1)
isEmpty()ตรวจสอบว่าสแตกว่างหรือไม่O(1)
isFull()ตรวจสอบว่าสแตกเต็มหรือไม่ (ถ้าใช้อาเรย์คงที่)O(1)

ภาวะผิดปกติของสแตก

  • Stack Overflow: การ push เมื่อสแตกเต็มแล้ว
  • Stack Underflow: การ pop หรือ peek เมื่อสแตกว่าง

4.2 ตัวอย่างโค้ดสแตก

ภาษา Python

class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        self.items.append(item)
    
    def pop(self):
        if self.is_empty():
            raise IndexError("Stack Underflow")
        return self.items.pop()
    
    def peek(self):
        if self.is_empty():
            raise IndexError("Stack is empty")
        return self.items[-1]
    
    def is_empty(self):
        return len(self.items) == 0
    
    def size(self):
        return len(self.items)


# การใช้งาน
s = Stack()
s.push(10)
s.push(20)
s.push(30)
print(s.pop())   # 30 (ตัวสุดท้ายที่เข้า ออกก่อน)
print(s.peek())  # 20
print(s.pop())   # 20
print(s.pop())   # 10

ภาษา C

#include <stdio.h>
#define MAX 100

typedef struct {
    int items[MAX];
    int top;
} Stack;

void init(Stack *s) {
    s->top = -1;
}

int is_empty(Stack *s) {
    return s->top == -1;
}

int is_full(Stack *s) {
    return s->top == MAX - 1;
}

void push(Stack *s, int value) {
    if (is_full(s)) {
        printf("Stack Overflow\n");
        return;
    }
    s->items[++s->top] = value;
}

int pop(Stack *s) {
    if (is_empty(s)) {
        printf("Stack Underflow\n");
        return -1;
    }
    return s->items[s->top--];
}

int peek(Stack *s) {
    if (is_empty(s)) {
        printf("Stack is empty\n");
        return -1;
    }
    return s->items[s->top];
}

int main() {
    Stack s;
    init(&s);
    push(&s, 10);
    push(&s, 20);
    push(&s, 30);
    printf("%d\n", pop(&s));  // 30
    return 0;
}

4.3 คิว (Queue) และหลักการ FIFO

คิวคือโครงสร้างข้อมูลที่การเพิ่มเกิดขึ้นที่ด้านท้าย (rear) และการลบเกิดขึ้นที่ด้านหน้า (front)

หลักการ FIFO (First-In, First-Out) คือ ตัวที่เข้ามาก่อนจะออกก่อน เปรียบเสมือนคนต่อแถวซื้อตั๋ว

graph LR
    subgraph Queue[คิว - FIFO]
        direction LR
        Front[หน้า] --> Q1([10]) --> Q2([20]) --> Q3([30]) --> Rear[ท้าย]
    end
    
    Enqueue[enqueue 40] --> Q3
    Dequeue[dequeue] --> Q1

การดำเนินการกับคิว

การดำเนินการคำอธิบายความซับซ้อน
enqueue(x)ใส่ x ที่ด้านท้ายO(1)
dequeue()เอาตัวที่ด้านหน้าออกและคืนค่าO(1)
front()ดูค่าที่ด้านหน้าโดยไม่เอาออกO(1)
rear()ดูค่าที่ด้านท้ายโดยไม่เอาออกO(1)
isEmpty()ตรวจสอบว่าคิวว่างหรือไม่O(1)

4.4 ตัวอย่างโค้ดคิว

ภาษา Python

from collections import deque

class Queue:
    def __init__(self):
        self.items = deque()
    
    def enqueue(self, item):
        self.items.append(item)
    
    def dequeue(self):
        if self.is_empty():
            raise IndexError("Queue Underflow")
        return self.items.popleft()
    
    def front(self):
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self.items[0]
    
    def is_empty(self):
        return len(self.items) == 0
    
    def size(self):
        return len(self.items)


# การใช้งาน
q = Queue()
q.enqueue(10)
q.enqueue(20)
q.enqueue(30)
print(q.dequeue())  # 10 (ตัวแรกที่เข้า ออกก่อน)
print(q.front())    # 20
print(q.dequeue())  # 20

4.5 คิวแบบวงกลม (Circular Queue)

คิวธรรมดาเมื่อ dequeue แล้วพื้นที่ด้านหน้าจะเสียเปล่าไป คิวแบบวงกลมแก้ไขโดยให้ด้านท้ายเชื่อมกลับไปด้านหน้าเมื่อถึงขอบเขต

graph LR
    subgraph CircularQueue[คิวแบบวงกลม]
        direction LR
        Q0([10]) --> Q1([20]) --> Q2([30]) --> Q3([ ])
        Q3 -.->|เชื่อมวงกลม| Q0
    end

ตัวอย่างโค้ดคิวแบบวงกลม (ภาษา C)

#include <stdio.h>
#define MAX 5

typedef struct {
    int items[MAX];
    int front, rear;
} CircularQueue;

void init(CircularQueue *q) {
    q->front = -1;
    q->rear = -1;
}

int is_empty(CircularQueue *q) {
    return q->front == -1;
}

int is_full(CircularQueue *q) {
    return (q->rear + 1) % MAX == q->front;
}

void enqueue(CircularQueue *q, int value) {
    if (is_full(q)) {
        printf("Queue Overflow\n");
        return;
    }
    if (is_empty(q)) {
        q->front = 0;
    }
    q->rear = (q->rear + 1) % MAX;
    q->items[q->rear] = value;
}

int dequeue(CircularQueue *q) {
    if (is_empty(q)) {
        printf("Queue Underflow\n");
        return -1;
    }
    int value = q->items[q->front];
    if (q->front == q->rear) {
        q->front = -1;
        q->rear = -1;
    } else {
        q->front = (q->front + 1) % MAX;
    }
    return value;
}

4.6 เด็กซ์ (Deque)

เด็กซ์ย่อมาจาก Double-Ended Queue คือคิวที่สามารถเพิ่มและลบได้ทั้งสองด้าน (หน้าและท้าย)

    subgraph Deque[เด็กซ์]
        direction LR
        Front[หน้า] <==> D1([10]) <==> D2([20]) <==> D3([30]) <==> Rear[ท้าย]
    end
    
    PushFront[push_front 5] --> D1
    PushBack[push_back 40] --> D3
    PopFront[pop_front] --> D1
    PopBack[pop_back] --> D3

4.7 การประยุกต์ใช้

โครงสร้างการประยุกต์ใช้
สแตกฟีเจอร์ยกเลิก (undo) ในโปรแกรมแก้ไขข้อความ, ตรวจสอบวงเล็บคู่กัน, แปลงนิพจน์อินฟิกซ์เป็นโพสฟิกซ์, เรียกฟังก์ชันในคอมพิวเตอร์ (call stack)
คิวระบบคิวบริการ (ธนาคาร ร้านอาหาร), การจัดลำดับงานพิมพ์ (print spooler), การทำงานแบบ BFS ในกราฟ, เครือข่ายคอมพิวเตอร์
คิวแบบวงกลมเบฟเฟอร์แบบวงกลม (circular buffer) ในระบบฝังตัว
เด็กซ์แอปดูรูปภาพก่อนหน้า/ถัดไป, การจัดตารางงานแบบขั้นตอน

ภาคผนก

ภาคผนก 4.1 โค้ดตัวอย่างสแตกและคิวภาษา C / Python / Java

ภาษา Java – คลาส Stack:

import java.util.EmptyStackException;

public class MyStack<T> {
    private java.util.ArrayList<T> items = new java.util.ArrayList<>();
    
    public void push(T item) {
        items.add(item);
    }
    
    public T pop() {
        if (isEmpty()) throw new EmptyStackException();
        return items.remove(items.size() - 1);
    }
    
    public T peek() {
        if (isEmpty()) throw new EmptyStackException();
        return items.get(items.size() - 1);
    }
    
    public boolean isEmpty() {
        return items.isEmpty();
    }
}

ภาคผนก 4.2 ตัวอย่างกรณีศึกษาการใช้สแตกในเครื่องมือพัฒนาซอฟต์แวร์

เครื่องมือแก้ไขข้อความส่วนใหญ่ใช้สแตกเก็บประวัติการแก้ไขเพื่อฟีเจอร์ undo ทุกครั้งที่ผู้ใช้แก้ไขข้อความ จะ push การกระทำนั้นเข้าไปในสแตก เมื่อกด undo จะ pop การกระทุล่าสุดออกแล้วย้อนกลับ
