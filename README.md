2. ปัญญาประดิษฐ์ เหมาะมากหากเพิ่ม Search Algorithm, Optimization, Graph Algorithm และ Algorithms สำหรับ Machine Learning

## คำอธิบายรายวิชา อัลกอริทึม (Description of Algorithms)

ศึกษาแนวคิด หลักการ และกระบวนการออกแบบอัลกอริทึมเพื่อแก้ปัญหาทางคอมพิวเตอร์ การวิเคราะห์ประสิทธิภาพของอัลกอริทึมด้านเวลาและพื้นที่ การวิเคราะห์ความซับซ้อนด้วย Big-O, Big-Ω และ Big-Θ เทคนิคการออกแบบอัลกอริทึม ได้แก่ การแบ่งและพิชิต (Divide and Conquer) การออกแบบแบบละโมบ (Greedy) การโปรแกรมพลวัต (Dynamic Programming) การย้อนรอย (Backtracking) และ Branch and Bound ศึกษาอัลกอริทึมสำหรับการค้นหา การเรียงลำดับ การเรียกซ้ำ และอัลกอริทึมบนกราฟ เช่น BFS, DFS, Shortest Path และ Minimum Spanning Tree รวมถึงแนวคิดด้าน Computational Complexity, NP-Complete และการประยุกต์ใช้อัลกอริทึมกับปัญหาด้านปัญญาประดิษฐ์ การค้นคืนสารสนเทศ การค้นหาเวกเตอร์ และระบบ RAG/GraphRAG พร้อมทั้งฝึกการออกแบบ วิเคราะห์ และพัฒนาอัลกอริทึมด้วยภาษาโปรแกรมที่เหมาะสม

## วัตถุประสงค์การเรียนรู้รายวิชาอัลกอริทึม (Objective of Learning)

1. อธิบายแนวคิดและหลักการของอัลกอริทึม รวมถึงองค์ประกอบ ขั้นตอน และคุณสมบัติของอัลกอริทึมได้
2. วิเคราะห์ปัญหาและออกแบบอัลกอริทึม โดยใช้ Pseudocode, Flowchart และแนวคิดเชิงขั้นตอนในการแก้ปัญหาได้อย่างเป็นระบบ
3. วิเคราะห์ประสิทธิภาพของอัลกอริทึม ทั้งด้านเวลาและพื้นที่ โดยใช้ Big-O, Big-Ω และ Big-Θ ได้
4. ประยุกต์ใช้โครงสร้างข้อมูลและอัลกอริทึม สำหรับการค้นหา การเรียงลำดับ การจัดการข้อมูล และการแก้ปัญหาประเภทต่าง ๆ ได้อย่างเหมาะสม
5. ออกแบบและประยุกต์ใช้เทคนิคการออกแบบอัลกอริทึม เช่น Divide and Conquer, Greedy, Dynamic Programming, Backtracking และ Branch and Bound ได้
6. ประยุกต์ใช้อัลกอริทึมด้านกราฟ เช่น BFS, DFS, Shortest Path, Minimum Spanning Tree และ Graph Traversal เพื่อแก้ปัญหาที่มีความสัมพันธ์ระหว่างข้อมูลได้
7. เปรียบเทียบและเลือกใช้อัลกอริทึมที่เหมาะสม โดยพิจารณาความถูกต้อง ประสิทธิภาพ ความซับซ้อน และข้อจำกัดของปัญหา
8. พัฒนาและทดสอบอัลกอริทึมด้วยภาษาโปรแกรม พร้อมตรวจสอบความถูกต้องและประสิทธิภาพของโปรแกรมได้
9. ประยุกต์ใช้อัลกอริทึมกับเทคโนโลยีสมัยใหม่ เช่น AI, Machine Learning, Information Retrieval, RAG และ GraphRAG ในระดับพื้นฐานได้
10. คิดวิเคราะห์และแก้ปัญหาเชิงคอมพิวเตอร์อย่างเป็นระบบ สามารถอธิบายเหตุผลในการเลือกแนวทางและประเมินผลลัพธ์ของอัลกอริทึมได้
