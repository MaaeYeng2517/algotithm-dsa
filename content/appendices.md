# ภาคผนกท้ายเล่ม

## ภาคผนก A คำศัพท์และคำย่อ

| คำศัพท์ | ความหมาย |
|:---|:---|
| อัลกอริทึม (Algorithm) | ชุดขั้นตอนแก้ปัญหาอย่างเป็นระบบ |
| โครงสร้างข้อมูล (Data Structure) | วิธีการจัดเก็บและจัดระเบียบข้อมูล |
| อินพุต (Input) | ข้อมูลที่ป้อนเข้าสู่กระบวนการ |
| เอาต์พุต (Output) | ผลลัพธ์ที่ได้จากกระบวนการ |
| บิ๊กโอ (Big O) | สัญลักษณ์บอกขอบเขตบนของความซับซ้อน |
| บิ๊กโอเมกา (Big Ω) | สัญลักษณ์บอกขอบเขตล่างของความซับซ้อน |
| บิ๊กเธตา (Big Θ) | สัญลักษณ์บอกขอบเขตทั้งสองด้านของความซับซ้อน |
| ภาษาเทียม (Pseudocode) | ภาษากึ่งโปรแกรมใช้เขียนอัลกอริทึม |
| ผังงาน (Flowchart) | แผนภาพแสดงขั้นตอนอัลกอริทึม |
| การเรียกซ้ำ (Recursion) | ฟังก์ชันเรียกตัวเอง |
| ลูป (Loop) | การทำซ้ำคำสั่ง |
| สแตก (Stack) | โครงสร้างข้อมูลแบบ LIFO |
| คิว (Queue) | โครงสร้างข้อมูลแบบ FIFO |
| ลิงก์ลิสต์ (Linked List) | โครงสร้างข้อมูลแบบโหนดเชื่อมโยงกัน |
| ไบนารีเซิร์ชทรี (BST) | ต้นไม้ค้นหาไบนารี |
| ตารางแฮช (Hash Table) | โครงสร้างข้อมูลเก็บคู่คีย์-ค่า |
| กราฟ (Graph) | โครงสร้างข้อมูลจุดยอดและขอบ |
| ไดจ์สตรา (Dijkstra) | อัลกอริทึมหาเส้นทางสั้นที่สุด |
| ไดนามิกโปรแกรมมิง (DP) | เทคนิคแก้ปัญหาโดยเก็บผลลัพธ์ปัญหาย่อย |

## ภาคผนก B คำแนะนำการเขียนโปรแกรมสำหรับนักศึกษา

### 1. การตั้งชื่อตัวแปรและฟังก์ชัน
- ใช้ชื่อที่อ่านแล้วรู้ความหมาย เช่น `studentAge`, `calculateTotal`
- ใช้ CamelCase สำหรับตัวแปรและฟังก์ชันใน Java/JavaScript
- ใช้ snake_case ใน Python เช่น `student_age`

### 2. การเว้นระยะและการจัดรูปแบบโค้ด
- เว้นวรรคให้เหมาะสมระหว่างตัวดำเนินการ เช่น `a + b` ไม่ใช่ `a+b`
- ย่อหน้า (indent) ให้ชัดเจนในบล็อกคำสั่ง
- 上括号และลงเครื่องหมายปีกกาให้ตรงกัน

### 3. การทดสอบและแก้ไขข้อผิดพลาด
- ทดสอบกับข้อมูลปกติ ข้อมูลขอบเขต และข้อมูลผิดปกติ
- ใช้ Desk Check เดินผ่านอัลกอริทึมด้วยตนเองก่อนรันโปรแกรม
- ใช้ debugger หรือคำสั่ง print เพื่อติดตามค่าตัวแปร
