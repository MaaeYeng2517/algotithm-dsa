# บทที่ 2 การวิเคราะห์ความซับซ้อนและสัญลักษณ์บิ๊กโอ (Big O)

## วัตถุประสงค์การเรียนรู้
เมื่อเรียนจบบทนี้ นักศึกษาจะสามารถ
1. อธิบายแนวคิดการวิเคราะห์ความซับซ้อนของอัลกอริทึม
2. ใช้สัญลักษณ์บิ๊กโอ (Big O), บิ๊กโอเมกา (Big Ω) และบิ๊กเธตา (Big Θ)
3. วิเคราะห์เวลาและพื้นที่ที่อัลกอริทึมใช้จากโค้ดต้นฉบับ
4. เปรียบเทียบประสิทธิภาพของอัลกอริทึมหลายชนิด
5. ระบุกรณีที่ดีที่สุด (Best Case), กรณีเฉลี่ย (Average Case) และกรณีแย่ที่สุด (Worst Case)

## การประเมิน

|:---|:---:|:---|
| โจทย์วิเคราะห์ความซับซ้อนเป็นรายบุคคล | 20% | วิเคราะห์จากโค้ดตัวอย่างที่กำหนด |

| การเข้าร่วมกิจกรรมจับคู่อัลกอริทึมกับความซับซ้อน | 10% | กิจกรรมกลุ่มในชั้นเรียน |

## 2.1 ทำไมต้องวิเคราะห์ความซับซ้อน

เมื่อแก้ปัญหาเดียวกันอาจมีอัลกอริทึมหลายวิธี เช่น การค้นหาชื่อในสมุดโทรศัพท์สามารถค้นทีละหน้า (เชิงเส้น) หรือเปิดกึ่งกลางแล้วตัดครึ่ง (ไบนารีเซิร์ช) เราต้องการทราบว่าวิธีใดเร็วกว่า โดยเฉพาะเมื่อข้อมูลมีจำนวนมาก

### ปัจจัยที่ส่งผลต่อความเร็ว
- ขนาดของอินพุต (n)
- ความเร็วของซีพียู
- ภาษาโปรแกรมที่ใช้
- ระบบปฏิบัติการ

แต่สำหรับการเปรียบเทียบอัลกอริทึม เราสนใจ **ขนาดอินพุต (n)** เป็นหลัก โดยไม่คำนึงถึงฮาร์ดแวร์

## 2.2 สัญลักษณ์บิ๊กโอ (Big O), บิ๊กโอเมกา (Big Ω) และบิ๊กเธตา (Big Θ)

### บิ๊กโอ (Big O) – กรณีแย่ที่สุด (Upper Bound)
บิ๊กโอบอกว่าเวลาทำงานจะไม่เกินค่านี้ ในกรณีแย่ที่สุด

**นิยามทางคณิตศาสตร์:**
ฟังก์ชัน f(n) = O(g(n)) ถ้ามีค่าคงที่ c และ n₀ ที่ทำให้ f(n) ≤ c·g(n) สำหรับทุก n ≥ n₀

### บิ๊กโอเมกา (Big Ω) – กรณีที่ดีที่สุด (Lower Bound)
บิ๊กโอเมกาบอกว่าเวลาทำงานจะเร็วกว่าหรือเท่ากับค่านี้เสมอ

**นิยาม:** f(n) = Ω(g(n)) ถ้า f(n) ≥ c·g(n) สำหรับทุก n ≥ n₀

### บิ๊กเธตา (Big Θ) – กรณีที่จำกัดทั้งสองด้าน (Tight Bound)
ใช้เมื่อบิ๊กโอและบิ๊กโอเมกาเท่ากัน

**นิยาม:** f(n) = Θ(g(n)) ถ้า f(n) = O(g(n)) และ f(n) = Ω(g(n))

### ตารางเปรียบเทียบความซับซ้อน

| สัญลักษณ์ | ชื่อ | คำอธิบาย | ตัวอย่างอัลกอริทึม |
|:---|:---|:---|:---|
| O(1) | คงที่ | เวลาไม่เปลี่ยนตามขนาดข้อมูล | การเข้าถึงอาเรย์โดยดัชนี |
| O(log n) | ลอการิทึม | เวลาเพิ่มช้ามากเมื่อข้อมูลเพิ่ม | การค้นหาแบบไบนารี |
| O(n) | เชิงเส้น | เวลาเพิ่มตามขนาดข้อมูล | การค้นหาเชิงเส้น |
| O(n log n) | กึ่งเชิงเส้น | เร็วกว่ากำลังสอง ช้ากว่าเชิงเส้น | เมอร์จ์ซอร์ต ควิกซอร์ต (เฉลี่ย) |
| O(n²) | กำลังสอง | เวลาเพิ่มเป็นกำลังสอง | บับเบิลซอร์ต ซิลレクชันซอร์ต |
| O(2ⁿ) | เอ็กซ์โพเนนเชียล | ช้ามาก เหมาะเฉพาะข้อมูลน้อย | การแก้ปัญหาแบบไบรท์ฟอร์ซ |
| O(n!) | แฟกทอเรียล | ช้าที่สุด | ปัญหากระเป๋าเดินทางแบบ brute force |

## 2.4 การนับขั้นตอนการทำงาน

### ตัวอย่างที่ 1: ลูปเดียว
```python
def Sum(n):
    total = 0          # 1 ขั้นตอน
    for i in range(n): # วน n รอบ
        total += i     # 1 ขั้นตอนต่อรอบ
    return total       # 1 ขั้นตอน
```
จำนวนขั้นตอนประมาณ = 1 + n + 1 = n + 2 → **O(n)**

### ตัวอย่างที่ 2: ลูปซ้อนสองชั้น
```python
def PrintPairs(n):
    for i in range(n):      # วน n รอบ
        for j in range(n):  # วน n รอบต่อ i แต่ละตัว
            print(i, j)     # 1 ขั้นตอน
```
จำนวนขั้นตอน = n × n = n² → **O(n²)**

### ตัวอย่างที่ 3: ลูปหารครึ่ง
```python
def BinarySearch(arr, target):
    left = 0
    right = len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```
แต่ละรอบตัดช่วงเหลือครึ่ง → วนประมาณ log₂ n รอบ → **O(log n)**

## 2.5 ความซับซ้อนเชิงพื้นที่ (Space Complexity)

นอกจากเวลาแล้ว เรายังวัดหน่วยความจำที่อัลกอริทึมใช้

| อัลกอริทึม | พื้นที่เพิ่มเติม | คำอธิบาย |
|:---|:---|:---|
| การค้นหาเชิงเส้น | O(1) | ใช้ตัวแปรไม่กี่ตัว |
| เมอร์จ์ซอร์ต | O(n) | ต้องใช้อาเรย์ชั่วคราวขนาด n |
| ควิกซอร์ต (แบบเรียกซ้ำ) | O(log n) | ใช้สแตกเรียกซ้ำลึก log n |
| ฟีโบนักชีแบบเรียกซ้ำธรรมดา | O(n) | ความลึกของสแตกเรียกซ้ำ |

---

## 2.6 กรณีที่ดีที่สุด เฉลี่ย และแย่ที่สุด

### ตัวอย่าง: การค้นหาเชิงเส้น
อาเรย์ `[10, 20, 30, 40, 50]` ค้นหาค่า 30

| กรณี | ตำแหน่งที่พบ | จำนวนครั้งที่เปรียบเทียบ | ความซับซ้อน |
|:---|:---|:---|:---|
| ที่ดีที่สุด (Best) | ตำแหน่งแรก | 1 | O(1) |
| ที่เฉลี่ย (Average) | ตำแหน่งกลาง | n/2 | O(n) |
| แย่ที่สุด (Worst) | ตำแหน่งสุดท้าย หรือไม่มี | n | O(n) |

---

## 2.7 ทฤษฎีบทมาสเตอร์ (Master Theorem) – แนะนำเบื้องต้น

ใช้วิเคราะห์อัลกอริทึมแบบแบ่งและพิชิตที่มีรูปแบบ:
T(n) = a·T(n/b) + f(n)

กรณีพื้นฐาน:
- ถ้า f(n) = O(n^log_b(a) - ε) → T(n) = Θ(n^log_b(a))
- ถ้า f(n) = Θ(n^log_b(a)) → T(n) = Θ(n^log_b(a) · log n)
- ถ้า f(n) = Ω(n^log_b(a) + ε) → T(n) = Θ(f(n))

ตัวอย่าง: เมอร์จ์ซอร์ต T(n) = 2T(n/2) + O(n) → log₂2 = 1, f(n) = O(n) → **T(n) = Θ(n log n)**

## แบบฝึกหัด

### ข้อที่ 1
จงวิเคราะห์ความซับซ้อนเชิงเวลาของลูปที่วนจาก 1 ถึง n

```python
for i in range(1, n+1):
    print(i)
```
**คำตอบ:** ลูปวน n รับ แต่ละรอบทำงาน O(1) → รวม **O(n)**

### ข้อที่ 2
จงหาความซับซ้อนของอัลกอริทึมค้นหาเชิงเส้นและค้นหาแบบไบนารี

| อัลกอริทึม | Best | Average | Worst |
|:---|:---|:---|:---|
| ค้นหาเชิงเส้น | O(1) | O(n) | O(n) |
| ค้นหาแบบไบนารี | O(1) | O(log n) | O(log n) |

### ข้อที่ 3
จงจัดลำดับอัลกอริทึมต่อไปนี้จากเร็วไปช้าตามสัญลักษณ์บิ๊กโอ

O(n!), O(2ⁿ), O(n²), O(n log n), O(n), O(log n), O(1)

**คำตอบ:** O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

## แบบปฏิบัติการข้อสอบ

### ข้อควบคุมเลือกตอบ (จำนวน 10 ข้อ)

**ข้อ 1.** สัญลักษณ์ใดบ่งบอกขอบเขตบนสุด (upper bound) ของความซับซ้อน
- ก. Big Ω
- ข. Big O
- ค. Big Θ
- ง. ทั้งหมดถูก

**ตอบ: ข**

**ข้อ 2.** อัลกอริทึมที่มีความซับซ้อน O(log n) ตัวอย่างใด
- ก. บับเบิลซอร์ต
- ข. การค้นหาเชิงเส้น
- ค. การค้นหาแบบไบนารี
- ง. ซิลレクชันซอร์ต

**ตอบ: ค**

**ข้อ 3.** ลูปซ้อนสองชั้นที่แต่ละลูปวน n รอบมีความซับซ้อนเท่าใด
- ก. O(n)
- ข. O(n²)
- ค. O(log n)
- ง. O(1)

**ตอบ: ข**

**ข้อ 4.** ในกรณีแย่ที่สุด การค้นหาเชิงเส้นมีความซับซ้อนเท่าใด
- ก. O(1)
- ข. O(log n)
- ค. O(n)
- ง. O(n²)

**ตอบ: ค**

**ข้อ 5.** ความซับซ้อนของเมอร์จ์ซอร์ตในทุกกรณีคือ
- ก. O(n)
- ข. O(n log n)
- ค. O(n²)
- ง. O(log n)

**ตอบ: ข**

**ข้อ 6.** อัลกอริทึมใดมีความซับซ้อน O(1)
- ก. การเข้าถึงสมาชิกในอาเรย์โดยดัชนี
- ข. การค้นหาแบบไบนารี
- ค. บับเบิลซอร์ต
- ง. เมอร์จ์ซอร์ต

**ตอบ: ก**

**ข้อ 7.** Big Θ หมายถึงอะไร
- ก. กรณีที่ดีที่สุดเท่านั้น
- ข. กรณีแย่ที่สุดเท่านั้น
- ค. จำกัดทั้งบนและล่าง (tight bound)
- ง. ความซับซ้อนเชิงพื้นที่

**ตอบ: ค**

**ข้อ 8.** ฟังก์ชัน f(n) = 3n² + 2n + 1 มีอัตราการเติบโตเป็น
- ก. O(n)
- ข. O(n²)
- ค. O(n log n)
- ง. O(2ⁿ)

**ตอบ: ข** (พจน์ที่มีเลขชี้กำลังสูงสุดคือ n²)

**ข้อ 9.** การเรียงลำดับที่มีความซับซ้อนแย่ที่สุด O(n²) ได้แก่ข้อใด
- ก. เมอร์จ์ซอร์ต
- ข. ควิกซอร์ต (กรณีเฉลี่ย)
- ค. บับเบิลซอร์ต
- ง. ฮีปซอร์ต

**ตอบ: ค**

**ข้อ 10.** อัลกอริทึมที่มีความซับซ้อน O(2ⁿ) เหมาะสำหรับ
- ก. ข้อมูลขนาดใหญ่มาก
- ข. ข้อมูลขนาดเล็กมาก
- ค. ทุกขนาดข้อมูล
- ง. ไม่เหมาะสำหรับข้อมูลใดๆ

**ตอบ: ข**

### ข้ออัตนัย (จำนวน 3 ข้อ)

**ข้อ 11.** ให้โค้ดต่อไปนี้ จงวิเคราะห์ความซับซ้อนเชิงเวลาและเชิงพื้นที่
```python
def example(n):
    i = 1
    while i < n:
        i = i * 2
```
**แนวทางตอบ:** i คูณ 2 ทุกรอบ → วน log₂ n รอบ → **เวลา O(log n), พื้นที่ O(1)**

**ข้อ 12.** จงเปรียบเทียบบับเบิลซอร์ตกับเมอร์จ์ซอร์ตในด้านความซับซ้อนเชิงเวลาทุกกรณี

**แนวทางตอบ:**
- บับเบิลซอร์ต: Best O(n), Average O(n²), Worst O(n²)
- เมอร์จ์ซอร์ต: Best O(n log n), Average O(n log n), Worst O(n log n)

**ข้อ 13.** จงอธิบายว่าเหตุใดการค้นหาแบบไบนารีจึงต้องใช้กับอาเรย์ที่เรียงลำดับแล้วเท่านั้น

**แนวทางตอบ:** เพราะไบนารีเซิร์ชอาศัยการเปรียบเทียบค่ากลางแล้วตัดครึ่งหนึ่งทิ้ง หากข้อมูลไม่เรียงลำดับ การทิ้งครึ่งหนึ่งอาจทำให้ขาดข้อมูลที่ต้องการ

## ภาคผนก

### ภาคผนก 2.1 ตารางอ้างอิงสัญลักษณ์ asymptotic notation

| สัญลักษณ์ | ความหมาย | ใช้บอกอะไร |
|:---|:---|:---|
| O(g(n)) | Big O | ขอบเขตบน (แย่ที่สุด) |
| Ω(g(n)) | Big Omega | ขอบเขตล่าง (ดีที่สุด) |
| Θ(g(n)) | Big Theta | ขอบเขตทั้งสองด้าน (กรณีทั่วไป) |
| o(g(n)) | Little O | กว่าอย่างเคร่งครัด (น้อยกว่าอย่างเดียว) |
| ω(g(n)) | Little Omega | มากกว่าอย่างเคร่งครัด |

### ภาคผนก 2.2 ตัวอย่างโค้ดวิเคราะห์ความซับซ้อนหลายภาษา

**ภาษา Python – คำนวณผลรวมอาเรย์ (O(n)):**
```python
def array_sum(arr):
    total = 0
    for x in arr:
        total += x
    return total
```

**ภาษา C – เมทริกซ์คูณเวกเตอร์ (O(n²)):**
```c
void mat_vec_mul(int n, int mat[n][n], int vec[n], int result[n]) {
    for (int i = 0; i < n; i++) {
        result[i] = 0;
        for (int j = 0; j < n; j++) {
            result[i] += mat[i][j] * vec[j];
        }
    }
}
```
